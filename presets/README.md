The three Tone buttons select the original EQ voicings directly. These JSON files also provide complete starting control settings.

Close the panel, copy one desired JSON file to `app/controls.json`, then reopen. This replaces only panel control settings. Endpoint selection remains in `app/devices.local.json`. Monitor outputs always reopen OFF at a low level; the preset does not enable pitch processing or load a plugin automatically.

Select the actual song key/scale before enabling pitch correction. Hard Tune defaults to chromatic notes. Natural correction uses a gentler amount and longer attack/release. Neither supplies formant or humanization controls.
